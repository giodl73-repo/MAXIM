# Crosscut Atlas

## The Big Picture

The Crosscut Atlas is a separate synthesis layer over the 13-section MAXIM
library. The regular sections answer "what field am I in?" The crosscuts answer
"what pattern am I seeing across fields?"

```
MAXIM LIBRARY

13 SECTIONS
field knowledge, directories, guides, volumes
   |
   v
13 CROSSCUTS
portable diagnostic lenses across the whole deck
   |
   v
SYNTHESIS
scale, flow, material, institution, interface, practice,
risk, evidence, system, tool, memory, and design pattern

Use sections when you need domain depth.
Use crosscuts when the same structure appears everywhere.
```

The crosscuts keep the same numbers as their home sections, but they live in
`crosscuts/` instead of inside the section directories. That makes them
publishable either as a separate companion book or as numbered companion essays
shipped with the 13 sections.

## How to Read the Atlas

The atlas can be read three ways.

```
PATH A: NUMBERED COMPANION
01 -> 02 -> 03 -> ... -> 13
Use when publishing beside the 13 sections.

PATH B: DIAGNOSTIC LOOP
problem -> choose lens -> inspect map -> jump to section guides
Use when a concrete question cuts across fields.

PATH C: SYNTHESIS ARC
patterns -> evidence -> risk -> systems -> tools -> infrastructure
-> time -> material -> flow -> scale -> institutions -> interfaces
-> practice -> patterns
Use when learning the whole reference library as one connected system.
```

The synthesis arc is not the only valid order. It is the order used by the
measured build-out because each R1 panel recommended the next lens.

## What Makes a Crosscut Different From a Section

| Section Guide | Crosscut Guide |
|---|---|
| Goes deep inside one field | Moves across all fields |
| Teaches the domain's own vocabulary | Teaches portable diagnostic vocabulary |
| Anchored in directories and volumes | Anchored in recurring structure |
| Best for learning a subject | Best for recognizing a pattern |
| Asks "what is true here?" | Asks "where else does this structure appear?" |

Crosscuts do not replace sections. They make the sections talk to one another.

## Common Confusion Points

**Crosscut does not mean shallow** — A crosscut is not a quick summary. It is a
deep diagnostic lens that stays portable across fields.

**Same number, separate layer** — The numbers match the 13 section homes, but
the files live under `crosscuts/` so the atlas can publish separately.

**One home section, all-section reach** — Each crosscut has a home section for
numbering and tone, but every guide maps the lens across all 13 sections.

**A lens is not a taxonomy** — Crosscuts are tools for seeing structure. Many
problems require more than one lens.

## Decision Cheat Sheet

| If you need to... | Start With | Key Caveat |
|---|---|---|
| Publish the crosscuts as a book | This overview, then 01 through 13 | Keep the numbered home-section mapping visible |
| Attach crosscuts to section volumes | Use each crosscut's number as its section companion | The crosscut still belongs to the separate atlas layer |
| Diagnose an unfamiliar problem | Use the Diagnostic Router | A problem may need several lenses in sequence |
| Build a learning path | Use the Synthesis Arc | The arc is a recommended route, not a dependency graph |
| Check quality | Require Big Picture, layered sections, cross-library map, cheat sheet, and confusion points | Lite polish is not sufficient for atlas status |
| Extend the atlas later | Add only lenses that cut across most sections | Do not add narrow domain topics as crosscuts |
