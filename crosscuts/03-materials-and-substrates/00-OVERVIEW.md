# 03 — Materials & Substrates

## The Big Picture

This crosscut is the **Material Culture companion atlas**. It uses section
number 3 because material culture makes the substrate visible: pigment, fiber,
clay, glass, metal, polymer, paper, wood, leather, stone, rope, dye, coating,
and composite all teach the same lesson in different media.

Time, memory, tools, infrastructure, bodies, buildings, circuits, books, and
institutions all need something that carries form. Materials & Substrates asks
what the world is made of, what that made-of-ness permits, and where it fails.

```
MATERIALS AND SUBSTRATES

Every form needs a carrier.
Every carrier has structure, affordance, limit, and decay.

SUBSTANCE -------> STRUCTURE -------> PROPERTY
what it is         how arranged       what it can do
   |                  |                 |
   v                  v                 v
PROCESS --------> FORM ------------> INTERFACE
how made           shape and scale     where it meets others
   |                  |                 |
   v                  v                 v
USE ------------> DEGRADATION -----> REPAIR
load, signal,       wear, rot, drift   renewal or replacement
meaning             fatigue

Substrate is not background.
Substrate is possibility with constraints.
```

Read this as a **material stack**. A substance has structure. Structure creates
properties. Processing turns properties into form. Forms meet other forms at
interfaces. Use exposes the material to load, weather, signal, meaning, and
time. Degradation reveals limits. Repair decides whether continuity survives.

---

## Why This Belongs With Material Culture

Material culture is where abstract human intention becomes durable matter.
Pigment fixes color. Fiber holds tension. Clay stores shape through fire. Glass
transmits light. Metal carries load and current. Polymer trades permanence for
formability. Paper stores memory. Wood, leather, masonry, rope, and composites
carry craft lineages inside their structure.

```
intention -> material choice -> process -> artifact -> use history
```

| Material Family | What It Makes Possible | What It Demands |
|---|---|---|
| Pigments and dyes | stable color, identity, signal | lightfastness, binder compatibility |
| Fibers and textiles | flexible strength, clothing, shelter | twist, weave, wear, moisture control |
| Ceramics and glass | heat stability, hardness, transparency | firing control, brittleness management |
| Metals | ductility, conductivity, structure | alloying, corrosion control, fatigue design |
| Polymers | cheap shaping, insulation, lightness | aging, additives, end-of-life handling |
| Paper and wood | memory, structure, workability | moisture, grain, insects, fire |
| Stone and masonry | compression, permanence, enclosure | joints, foundations, weathering |

The bridge:

```
design is never substrate-free
the medium participates in the idea
```

## Layer 1: Substance, Structure, and Property

The same substance can behave differently when its structure changes.

```
chemistry -> microstructure -> property -> performance
```

| Structural Scale | Example | Why It Matters |
|---|---|---|
| Atomic | crystal lattice, bonding, defects | hardness, conductivity, melting |
| Molecular | polymer chain, cellulose, protein | flexibility, degradation, solubility |
| Grain / fiber | wood grain, metal grain, textile twist | strength direction, crack path |
| Porosity | ceramic body, soil, foam, bone | permeability, insulation, brittleness |
| Layer | paint film, laminate, composite | interface failure, anisotropy |
| Macro form | beam, vessel, sheet, rope | load path, ergonomics, use |

The diagnostic move:

```
do not ask only "what is it made of?"
ask "how is it arranged?"
```

---

## Layer 2: Process Makes Material

Processing is not after material choice. Processing is part of the material.

```
raw material -> preparation -> forming -> transformation -> finishing
```

| Process | Material Change | Failure If Misread |
|---|---|---|
| Firing | clay becomes ceramic, glaze melts | warping, cracking, underfire |
| Alloying | metal composition changes behavior | brittleness, corrosion, wrong phase |
| Weaving | fiber becomes fabric structure | weak drape, tear path, shrinkage |
| Casting | melt takes form | porosity, inclusion, residual stress |
| Polymerization | monomer becomes chain network | wrong cure, aging, toxicity |
| Seasoning / drying | moisture state stabilizes | checking, mold, dimensional movement |
| Coating | surface gains protection or signal | adhesion loss, incompatibility |

**Old world -> new world bridge:** in manufacturing this is process control:
temperature, time, pressure, feedstock, tooling, tolerance. In software and data
systems the analog is build pipeline, runtime environment, schema migration, and
deployment process. The artifact inherits the process that made it.

## Layer 3: Interfaces and Compatibility

Most material failures start where one thing meets another.

```
material A -> interface -> material B
```

| Interface | Compatibility Question | Failure Mode |
|---|---|---|
| Paint and substrate | Will it wet, adhere, and move together? | peeling, blistering |
| Metal joint | Are galvanic and thermal effects controlled? | corrosion, fatigue crack |
| Composite layers | Is load transferred across the matrix? | delamination |
| Textile seam | Does stitch match fabric load and stretch? | seam failure |
| Implant and tissue | Is immune and mechanical response acceptable? | rejection, inflammation |
| Data medium and reader | Can future tools decode the format? | unreadable archive |
| Building envelope | Do air, water, vapor, and heat paths align? | condensation, rot |

Interfaces are where hidden assumptions become physical. A perfect material in
isolation can fail because the neighboring material expands, corrodes, absorbs,
abrades, or ages differently.

## Layer 4: Substrate as Memory

Substrates carry traces. Some are deliberate records; others are accidental
archives.

```
event -> mark -> preserved trace -> readable memory
```

| Substrate | What It Can Remember | What Can Erase It |
|---|---|---|
| Stone | inscription, tool mark, weathering | erosion, reuse, breakage |
| Paper | text, drawing, bureaucracy | fire, water, acid, neglect |
| Soil | pollen, chemistry, disturbance | plowing, contamination |
| Bone / tissue | diet, disease, ancestry | decay, heat, sampling damage |
| Metal | stress, corrosion, manufacturing marks | melting, polishing, fatigue |
| Software storage | logs, commits, datasets | migration loss, bit rot, schema loss |
| City fabric | routes, property lines, infrastructure | redevelopment, disaster, policy |

Memory is material before it is intellectual. The archive depends on what the
substrate can survive and what later readers can decode.

---

## Layer 5: Degradation, Repair, and End of Life

Every substrate has a preferred way to fail.

```
load + environment + time -> degradation path
```

| Material / Substrate | Typical Degradation | Repair Logic |
|---|---|---|
| Wood | rot, insects, checking, fire | dry, replace, reinforce, preserve grain logic |
| Metal | corrosion, fatigue, creep | isolate, coat, anneal, replace, inspect cracks |
| Ceramic / glass | brittle fracture, thermal shock | prevent crack initiation; repair is limited |
| Textile | abrasion, UV, mildew, seam failure | patch, darn, stabilize, control storage |
| Polymer | UV, oxidation, plasticizer loss | shield, replace, design for lifecycle |
| Masonry | mortar decay, settlement, freeze-thaw | repoint, drain, respect load path |
| Data | bit rot, format loss, context loss | migrate, checksum, document provenance |

End of life is part of design:

```
repairable, recyclable, biodegradable, archival, disposable, or toxic legacy
```

Those are not afterthoughts. They are material choices.

## What This Crosscut Is For

Use it when the carrier is doing more work than the story admits.

```
QUESTION                           FIRST DIAGNOSTIC MOVE

"Why did it fail?"              -> inspect substance, structure, interface, and environment
"Why did it survive?"           -> inspect substrate durability and preservation context
"Can it be repaired?"           -> identify what must remain invariant
"Can it scale?"                 -> inspect feedstock, process, waste, and lifecycle
"Can it be trusted as evidence?"-> inspect trace formation, preservation, and decoding
"Why does it feel different?"   -> inspect grain, texture, stiffness, weight, and process
```

The goal is to stop treating matter as passive. Substrate is one of the actors.

## Decision Cheat Sheet

| If you need to diagnose... | Start With | Key Caveat |
|---|---|---|
| Whether material choice is the root issue | Ask substance, structure, process, interface, use, and environment | Composition alone rarely explains performance |
| Whether a property claim is meaningful | Identify scale: atomic, molecular, grain, layer, macro form | Properties change with structure and processing |
| Whether a process made the failure | Trace preparation, forming, transformation, finishing, and storage | The artifact inherits its process history |
| Whether two materials are compatible | Inspect adhesion, movement, chemistry, moisture, heat, and load transfer | Interfaces fail even when both materials are sound |
| Whether a substrate preserves memory | Ask what trace formed, what survived, and what can still be decoded | Surviving marks are selected evidence |
| Whether repair preserves identity | Identify load path, surface, craft logic, and historical value | Repair changes the object while trying to preserve continuity |
| Whether end-of-life is acceptable | Map repair, reuse, recycling, biodegradation, toxicity, and disposal | Cheap materials can create expensive legacies |
| Whether a digital system has a substrate problem | Inspect hardware, storage medium, format, power, cooling, and provenance | "Virtual" systems still depend on physical carriers |

## Common Confusion Points

**Material is not just composition** — Steel is not just iron plus carbon. Wood
is not just cellulose. Glass is not just silica. Structure and process create
performance.

**Surface is not superficial** — Coatings, patinas, finishes, oxides, binders,
and interfaces often determine durability, color, adhesion, corrosion, and
meaning.

**Digital is not immaterial** — Code needs silicon, storage, power, cooling,
cables, displays, protocols, and formats. Digital memory fails materially and
institutionally.

**Repair is not replacement** — Replacement restores function. Repair tries to
preserve continuity, evidence, craft, or identity while restoring function.

**Durability is not always virtue** — Some materials should persist for
centuries. Others should safely decay. The right lifetime depends on use and
consequence.
