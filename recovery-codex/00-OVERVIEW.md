# Recovery Codex

## The Big Picture

The Recovery Codex is the **civilizational continuity layer** of MAXIM. The
sections teach domains. The crosscuts teach portable patterns. The Recovery
Codex asks a harder question:

```
If MAXIM were the only surviving reference,
what must a future society preserve, understand, rebuild, and avoid cargo-culting?
```

This is not a shortcut survival manual. It is a reconstruction map: what must be
known deeply enough to recover food, water, health, materials, measurement,
communication, governance, computation, craft, and judgment after loss.

```
RECOVERY CODEX

PRESERVE ------> UNDERSTAND ------> REBUILD
memory           principles         working capability
   |                 |                 |
   v                 v                 v
MEASURE -------> PRACTICE -------> INSTITUTION
units, tests      skill, repair      continuity,
and evidence      and judgment       law, teaching
   |                 |                 |
   v                 v                 v
TRANSMIT -----> ADAPT ---------> AVOID
language,         local materials    superstition,
archives,         and constraints    cargo cult,
education                           brittle imitation

The goal is not to preserve artifacts.
The goal is to preserve recoverable competence.
```

The Codex keeps the same 1-13 section numbering so it can publish in either of
two ways:

```
standalone book:    Recovery Codex 01 -> 13
section companion: each section ships with its matching recovery chapter
```

It is additive to the existing MAXIM manifest. `BILL-OF-MATERIALS.md` identifies
Card 0 / Read This First as the survival primer. `VOLUMES.md` identifies Annex I
and Annex II as lookup references for tool-specific material. The Recovery Codex
is different: it is the long-horizon continuity layer that explains how
capabilities remain recoverable when tools, supply chains, institutions, or
media are lost.

| Existing Layer | Purpose |
|---|---|
| Card 0 / Read This First | immediate survival primer: water, fire, shelter, food, tools, numbers |
| Deck sections | teach domains deeply |
| Crosscut Atlas | teach portable diagnostic lenses |
| Annex I / II | preserve fast lookup reference cards for programming, tools, and platforms |
| Recovery Codex | preserve rebuildable competence across generations |

## Recovery Is Not Reenactment

A future society may not have the same ores, fuels, chips, medicines, shipping
lanes, institutions, or climate. The Codex must therefore preserve principles,
not rituals.

```
artifact -> principle -> local substitute -> tested practice
```

| Bad Preservation | Better Preservation |
|---|---|
| Copy the old object exactly | Understand what function it performed |
| Memorize a process without variables | Preserve measurements, tolerances, and failure signs |
| Keep tools without training | Keep exercises, apprenticeships, and repair paths |
| Preserve laws without legitimacy | Preserve why rules worked and how they were revised |
| Preserve data without readers | Preserve encoding, provenance, and decoding methods |
| Preserve facts without tests | Preserve evidence, error models, and replication |

The Codex should make future rebuilding **adaptive**:

```
same need, different substrate, tested result
```

## The Recovery Ladder

Every recovery volume should distinguish five levels of continuity.

| Level | Name | Question |
|---|---|---|
| 1 | Remember | What must not be forgotten? |
| 2 | Recognize | How can a future reader identify the phenomenon or resource? |
| 3 | Measure | What units, tests, signs, and thresholds matter? |
| 4 | Rebuild | What minimum working capability can be reconstructed? |
| 5 | Teach | How does the capability become transmissible practice? |

```
remember -> recognize -> measure -> rebuild -> teach
```

A volume that stops at facts is not enough. A volume must climb the ladder to
practice and transmission.

## Civilizational Failure Modes the Codex Must Resist

| Failure Mode | What It Looks Like | Codex Countermeasure |
|---|---|---|
| Cargo cult | copying forms without understanding functions | explain principles, tests, and failure signs |
| Tool orphaning | tools survive but no one knows how to use or repair them | preserve training sequences and maintenance logic |
| Measurement loss | units, calibration, and tolerances disappear | preserve metrology and reproducible reference methods |
| Archive rot | records survive without context or readers | preserve encoding, provenance, and language bridges |
| Institutional amnesia | societies repeat avoidable collapse patterns | preserve case histories, incentives, and warning signs |
| Expertise bottleneck | knowledge dies with a small guild | preserve apprenticeships and teaching paths |
| Local mismatch | imported method fails in new conditions | preserve adaptation rules and substitution logic |
| Moral narrowing | technical recovery ignores human consequence | preserve ethics, governance, care, and meaning |

## Minimum Viable Civilization Checklist

This is not a ranking of importance. It is a dependency map for recovery.

```
water + food + shelter + sanitation
        |
        v
measurement + materials + tools + repair
        |
        v
language + archives + teaching + institutions
        |
        v
energy + transport + medicine + computation
        |
        v
science + art + law + judgment
```

| Capability | Recovery Question |
|---|---|
| Water | Can people find, move, store, and keep it safe? |
| Food | Can ecosystems and agriculture remain productive? |
| Shelter | Can heat, water, structure, and ventilation be controlled? |
| Sanitation | Can waste be separated from bodies, food, and water? |
| Measurement | Can units and tests be reproduced? |
| Materials | Can local substrates be transformed and repaired? |
| Tools | Can people extend hand, eye, memory, and force? |
| Communication | Can knowledge cross distance and generation? |
| Institutions | Can trust, roles, law, and teaching persist? |
| Energy | Can work be powered without exhausting the base? |
| Medicine | Can suffering, infection, injury, and birth be handled? |
| Computation | Can logic, data, and automation be recovered when substrate allows? |
| Meaning | Can people remember why rebuilding is worth doing? |

## Decision Cheat Sheet

| If you need to... | Start With | Key Caveat |
|---|---|---|
| Decide what recovery chapter to write first | Pick the section whose loss would block many others | Dependencies are local; water may outrank electricity in one place, sanitation in another |
| Preserve a capability | Record function, principle, materials, process variables, tests, and repair | A recipe without failure signs is fragile |
| Avoid cargo-cult reconstruction | Ask what problem the old artifact solved and how success was measured | Form can survive after function is forgotten |
| Teach future practitioners | Include exercises, inspection cues, common errors, and apprenticeship path | Facts do not become skill without feedback |
| Preserve scientific knowledge | Keep units, instruments, uncertainty, replication, and negative results | Conclusions without method become doctrine |
| Preserve institutions | Keep roles, records, appeal paths, revision rules, and legitimacy logic | Rules without trust become coercion or theater |
| Preserve digital knowledge | Keep encoding, hardware assumptions, data models, and human-readable fallbacks | Bits without readers are decorative noise |
| Publish the Codex | Keep the 1-13 mapping parallel to MAXIM sections | This is a continuity layer, not a replacement for the library |

## Common Confusion Points

**Recovery is not nostalgia** — The point is not to recreate a lost modern world
exactly. The point is to recover competence under real constraints.

**Low-tech is not anti-science** — Many robust recovery paths use simple tools,
but they should preserve measurement, evidence, and error correction.

**High-tech is not magic** — Electricity, computation, medicine, and networks
depend on materials, power, standards, institutions, and maintenance.

**An archive is not enough** — Knowledge must be readable, testable, teachable,
and connected to practice.

**Civilization is not only infrastructure** — Law, trust, art, language,
memory, care, and judgment are survival systems too.

## Build Standard for Future Recovery Volumes

Each volume should follow the MAXIM gold standard:

1. Start with a Big Picture diagram.
2. Identify minimum viable capability.
3. Separate principle from artifact.
4. Name materials, measurements, tools, and failure signs.
5. Include recovery ladders: remember, recognize, measure, rebuild, teach.
6. Include common confusions and dangerous cargo-cult traps.
7. End with a decision cheat sheet.

The Recovery Codex exists because a reference library should not only describe a
world. It should help a future one remain possible.
