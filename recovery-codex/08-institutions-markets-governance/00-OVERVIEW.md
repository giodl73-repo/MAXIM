# Recovery 08 — Institutions, Markets & Governance

## The Big Picture

This Recovery Codex volume belongs to **Social Sciences**. Its job is to
preserve the capability to coordinate beyond family scale: trust, law, money,
markets, education, public health, records, conflict resolution, and legitimate
authority.

```
INSTITUTIONS, MARKETS, AND GOVERNANCE

Civilization persists when cooperation can outlive mood, memory, and force.

TRUST -------> RULE -------> RECORD
reputation,     right, duty,   contract, case,
promise         boundary       account
   |              |              |
   v              v              v
ROLE --------> EXCHANGE ----> PUBLIC GOOD
office, skill,  money, market  water, road,
duty            ration         school, health
   |              |              |
   v              v              v
APPEAL ------> REVISION ---> LEGITIMACY
fair process    learning       consent under

Governance is not command.
```

## Minimum Viable Capability

A society has recovered this volume's core capability when it can keep records,
settle disputes, define rights and duties, manage shared resources, teach
children, maintain public health, exchange goods fairly, punish abuse without
revenge spirals, revise rules, and preserve legitimacy under stress.

```
trust -> rule -> record -> exchange -> public good -> appeal -> revision
```

## Layer 1: Trust, Law, and Records

| Institution | Recovery Use | Failure Mode |
|---|---|---|
| Promise / contract | coordinates future action | no enforcement |
| Property / use right | prevents constant conflict | dispossession |
| Court / hearing | resolves disputes | favoritism |
| Ledger | tracks debt and stores | fraud |
| Public notice | makes rule knowable | secret law |
| Appeal | corrects abuse | revenge |
| Archive | institutional memory | amnesia |

Rule:

```
no legitimate rule without record, procedure, and appeal
```

---

## Layer 2: Markets, Money, and Rationing

Exchange systems allocate scarcity. They can also hide exploitation.

| Mechanism | Best Use | Watch For |
|---|---|---|
| Barter | small local exchange | coincidence problem |
| Ledger credit | repeated trusted exchange | fraud, exclusion |
| Commodity money | wider trade | debasement, hoarding |
| Ration | emergency fairness | black markets |
| Price | scarcity signal | monopoly, desperation |
| Tax / contribution | public goods | legitimacy loss |
| Insurance / mutual aid | shared risk | moral hazard, capture |

Market rule:

```
exchange needs trust, units, enforcement, and fraud control
```

---

## Layer 3: Public Goods and Commons

Public goods are recovery multipliers: water, roads, sanitation, defense,
schools, archives, public health, and standards.

| Public Good | Governance Need |
|---|---|
| Water | rights, maintenance, contamination rules |
| Sanitation | enforcement, inspection, shared labor |
| Roads / bridges | upkeep, tolls or taxes, access |
| Schools | curriculum, teachers, broad literacy |
| Public health | surveillance, quarantine legitimacy |
| Weights and measures | market fairness |
| Commons | harvest limits, monitoring, sanctions |

Commons rule:

```
shared resource + no rule + no monitoring = future conflict
```

## Cargo-Cult Traps

| Trap | Why It Fails | Countermeasure |
|---|---|---|
| Law without legitimacy | people evade or rebel | procedure, appeal, public reason |
| Money without trust | becomes token theater | backing, ledger, enforcement |
| Charisma as institution | dies with leader | offices, succession, records |
| Secret records | power capture | public notice and audit |
| Emergency powers forever | recovery becomes domination | sunset, review, appeal |

## Practical Reconstruction Sequence

```
1. public records and visible rules
2. dispute process and appeal
3. shared stores, weights, measures, and ledgers
4. water, sanitation, road, and school duties
5. market rules and fraud control
6. public-health authority with trust safeguards
7. succession, audit, revision, and historical memory
```

## Decision Cheat Sheet

| If you need to... | Start With | Key Caveat |
|---|---|---|
| Restore trust | Public records, fair procedure, visible enforcement | Trust grows slowly and breaks quickly |
| Allocate scarcity | Choose price, ration, queue, duty, or mutual aid deliberately | Every allocation creates incentives |
| Govern commons | Define users, limits, monitoring, sanctions, appeal | Commons fail from both neglect and capture |
| Create money | Unit, backing, ledger, anti-fraud, tax acceptance | Money is social infrastructure |
| Handle emergency power | Scope, duration, review, support, appeal | Permanent emergency destroys legitimacy |
| Teach institutions | Case histories, role drills, ledgers, hearings | Civics without practice is weak |

## Common Confusion Points

**Governance is not bureaucracy** — It is the repair of coordination under
scarcity.

**Markets are institutions** — Prices need rules, records, trust, and enforcement.

**Legitimacy is practical** — Without it, people hide information and evade rules.

**Public goods are survival systems** — Water, roads, schools, health, and
archives are as real as machines.
