# Recovery 13 — People, Judgment & Leadership

## The Big Picture

This Recovery Codex volume belongs to **People**. Its job is to preserve the
human capabilities no archive can automate: judgment, courage, restraint,
teaching, care, leadership, succession, moral responsibility, and lives used as
compressed memory.

```

Civilization is rebuilt by persons under consequence.

   |              |              |
   v              v              v
JUDGMENT ----> LEADERSHIP -> SUCCESSION

   |              |              |
   v              v              v
BIOGRAPHY ---> MEMORY ----> RESPONSIBILITY

## Minimum Viable Capability

A society has recovered this volume's core capability when it can identify and
train competent people, distribute responsibility, teach judgment through cases,
protect against charismatic capture, preserve biographies of success and
failure, care for the vulnerable, and pass leadership without collapse.

```
character -> skill -> trust -> judgment -> leadership -> succession -> memory
```

| Biographical Lens | Recovery Use |
|---|---|

| Reformer | how institutions resist and change |
| Caregiver | what duty looks like under exhaustion |

teach lives as cases, not saints
```

## Cargo-Cult Traps

| Trap | Why It Fails | Countermeasure |
|---|---|---|
| Great-man worship | hides systems and teams | teach networks and constraints |
| Charisma as competence | trust misassigned | outcome records and accountability |
| Heroic burnout | best people break | rest, rotation, care |
| Purity tests | destroys coalition | roles, evidence, repair |
| No succession | knowledge dies | train deputies early |
| Blame culture | hides errors | just review and responsibility |

---

## Practical Reconstruction Sequence

```
1. identify essential roles and current holders
2. name deputies for every role
3. create biography casebooks of success and failure
4. teach decision review: facts, options, harms, uncertainty
5. rotate duties and train apprentices
6. create accountability, appeal, and removal paths
7. protect caregivers, teachers, makers, and stewards from burnout
```

## Decision Cheat Sheet

| If you need to... | Start With | Key Caveat |
|---|---|---|
| Choose a leader | Competence, restraint, trust, accountability | Charisma is not evidence |
| Teach judgment | Cases, consequences, uncertainty, review | Rules never cover every case |
| Preserve expertise | Apprentices, deputies, records, practice | One expert is a bottleneck |
| Handle failure | After-action review and repair | Blame without learning repeats harm |
| Prevent tyranny | Appeal, removal, transparency, distributed roles | Emergency power must end |
| Sustain caregivers | Rest, rotation, recognition, mental care | Exhausted helpers become casualties |

## Common Confusion Points

**Leadership is not domination** — It is responsibility for coordination under
consequence.

**Biography is not hero worship** — It is case-based memory of judgment.

**Care is infrastructure** — Societies lose capability when caregivers collapse.

**Succession is survival** — Any irreplaceable person is a single point of
failure.
