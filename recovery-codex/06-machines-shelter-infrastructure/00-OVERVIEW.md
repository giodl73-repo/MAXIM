# Recovery 06 — Machines, Shelter & Infrastructure

## The Big Picture

This Recovery Codex volume belongs to **Mechanics**. Its job is to preserve the
capability to build shelter, move water and waste, control heat, make mechanical
power, maintain roads and transport, and keep physical systems repairable.

```
MACHINES, SHELTER, AND INFRASTRUCTURE

Recovery becomes stable when people can shape force, heat, water, and load.

SHELTER -----> WATER -------> HEAT
roof, wall,     pump, pipe,     fire, stove,
drainage        drain, storage  insulation
   |              |              |
   v              v              v
STRUCTURE ---> MACHINE ----> TRANSPORT
load path       lever, wheel,   road, cart,
foundation      engine, pump    boat, bridge
   |              |              |
   v              v              v
MAINTAIN ----> STANDARD ---> TEACH
inspect,        parts, sizes,   builders,
repair          tolerances      mechanics

Infrastructure is not the thing built once.
It is the thing maintained before it fails.
```

## Minimum Viable Capability

A society has recovered this volume's core capability when it can build safe
shelter, separate clean and dirty water, cook and heat efficiently, move loads,
bridge gaps, maintain tools and machines, inspect structures, and teach
builders the difference between temporary success and durable safety.

```
shelter -> water/waste -> heat -> structure -> machine -> transport -> maintenance
```

## The Recovery Ladder

| Level | Recovery Task | What Must Survive |
|---|---|---|
| Remember | Load, water, heat, and wear destroy neglected systems | foundations, drainage, ventilation, inspection |
| Recognize | Identify unsafe structures, bad fires, contaminated drains, worn machines | cracks, smoke, leaks, rot, looseness |
| Measure | Track span, slope, level, temperature, flow, clearance, load | rods, plumb, level, gauges, logs |
| Rebuild | Make shelters, stoves, pumps, drains, roads, carts, bridges, workshops | tools, materials, standards |

## Layer 1: Shelter and Load Path

Shelter is controlled exposure: rain out, heat managed, smoke vented, structure
standing, pests limited, people dry.

| Shelter Element | Recovery Question | Failure Sign |
|---|---|---|
| Foundation | Where does load meet ground and water? | settlement, tilt, cracking |
| Roof | Where does water go in the worst storm? | leaks, sag, rot |
| Wall | What resists wind, heat, and intrusion? | bowing, damp, gaps |
| Floor | Is it dry, cleanable, and above water? | mold, pests, soft spots |
| Ventilation | Where do smoke and moisture leave? | cough, soot, condensation |
| Fire zone | Can heat be used without burning the shelter? | scorch, sparks, unstable chimney |

```
load path + water path + air path + fire path = shelter safety
```

---

## Layer 2: Water, Waste, and Plumbing

Infrastructure begins when water has a safe path and waste has a separate path.

| System | Minimum Rebuild | Watch For |
|---|---|---|
| Well / intake | protected source, cover, drainage away | surface contamination |
| Cistern | covered, cleanable, overflow controlled | algae, insects, cracks |
| Pipe / channel | slope, access, cleanouts | leaks, stagnation |
| Drain | away from shelter and wells | backflow, erosion |
| Latrine / sewer | downhill and isolated from water | groundwater contamination |
| Pump | maintainable seals, valves, handle | dry running, worn leather, air leaks |

Rule:

```
clean water never crosses dirty water
```

---

## Layer 3: Heat, Fire, and Mechanical Power

Heat is life, food safety, metallurgy, ceramics, sanitation, and danger.

| Capability | Recovery Use | Cargo-Cult Trap |
|---|---|---|
| Stove | cooking, warmth, fuel efficiency | smoke indoors |
| Chimney / flue | removes combustion products | draft failure and fire |
| Insulation | preserves heat and cool | trapping moisture |
| Kiln / furnace | ceramic, lime, metal | unknown temperatures |
| Lever / pulley | moves load | overload and rope failure |
| Wheel / axle | transport and machinery | bad bearings |
| Pump / waterwheel | fluid and power | no maintenance access |

Mechanical rule:

```
force path + friction + lubrication + inspection = machine life
```

## Cargo-Cult Traps

| Trap | Why It Fails | Countermeasure |
|---|---|---|
| Build without drainage | water ruins structure | design water path first |
| Smoke tolerated indoors | chronic disease and fire | vent combustion |
| Machine copied by shape | friction and tolerances ignored | test load, lubrication, wear |
| Bridge without inspection | hidden rot or fatigue | scheduled checks |
| No access panels | repair becomes demolition | design for maintenance |

## Practical Reconstruction Sequence

```
1. dry shelter and safe fire
2. protected water and separated waste
3. stoves, chimneys, drains, and cleanable floors
4. workshops with benches, vices, storage, and light
5. pumps, wheels, carts, roads, bridges, and mills
6. inspection logs and repair standards
7. apprenticeships for builders and maintainers
```

## Decision Cheat Sheet

| If you need to... | Start With | Key Caveat |
|---|---|---|
| Build shelter | Load path, water path, air path, fire path | A dry weak shelter and a strong wet shelter both fail |
| Move water | Source protection, slope, pump access, cleanouts | Pipes hide failure until disease appears |
| Use fire safely | Fuel, draft, chimney, clearance, spark control | Smoke is a health failure |
| Build a machine | Force path, friction, bearing, lubrication, maintenance | Shape is not mechanism |
| Build a bridge | Foundation, span, load, water scour, inspection | Floods test bridges more than ordinary traffic |
| Maintain infrastructure | Logs, access, spare parts, inspection intervals | Maintenance is cheaper than collapse |

---

## Common Confusion Points

**Infrastructure is process** — The bridge, pipe, stove, or road is only as good
as inspection and repair.

**Water is structural** — Drainage decides whether foundations, roads, and
shelter survive.

**Fire is both tool and predator** — Heat must be routed, vented, and bounded.

**Machines are wear systems** — Friction, lubrication, looseness, and fatigue
are not details.
