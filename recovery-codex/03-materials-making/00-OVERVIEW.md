# Recovery 03 — Materials & Making

## The Big Picture

This Recovery Codex volume belongs to **Material Culture**. Its job is to
preserve the capability to turn local matter into containers, tools, shelter,
cloth, paper, fuel, instruments, repairs, and durable records.

Health, water, food, navigation, and teaching all become material problems:
vessels for clean water, cloth for wounds, clay for storage, wood for shelter,
lime for sanitation, metal for tools, glass for observation, paper for records,
and rope for moving loads.

```
MATERIALS AND MAKING

Recovery becomes durable when matter can be shaped and repaired.

SOURCE -------> PROCESS -----> FORM
wood, clay,      cut, fire,     vessel, beam,
fiber, ore       weave, cast    sheet, tool
   |               |              |
   v               v              v
PROPERTY ----> USE --------> WEAR
strength,       store, cut,     rot, rust,
porosity,       bind, shelter   crack, tear
heat
   |               |              |
   v               v              v
REPAIR ------> STANDARD ---> TEACHING
patch, join,     grade, size,    craft lineage,
sharpen          tolerance       exercises

Material recovery is not object copying.
It is learning what a substance can become.
```

Read this as a **making stack**. Sources provide matter. Processes transform it.
Forms serve use. Properties decide performance. Wear reveals limits. Repair
extends life. Standards make parts and practices portable. Teaching preserves
craft.

---

## Minimum Viable Capability

A society has recovered this volume's core capability when it can:

1. Identify and test local wood, clay, stone, fiber, hide, bone, shell, sand,
   lime, pigments, ores, fuels, and binders.
2. Make containers for water, food, medicine, seed, records, and tools.
3. Produce basic cordage, textiles, mats, baskets, paper-like surfaces, and
   protective coverings.
4. Shape wood, stone, clay, glass, and metal with known limits and safety.
5. Make and maintain adhesives, coatings, mortar, soap, charcoal, lime, and
   simple ceramics.
6. Repair, sharpen, patch, join, seal, repoint, and reuse before discarding.
7. Teach material tests, process variables, failure signs, and safety practices.

```
identify -> test -> process -> use -> inspect -> repair -> teach
```

The minimum is not industrial abundance. The minimum is a material culture that
can keep essential things working.

## The Recovery Ladder

| Level | Recovery Task | What Must Survive |
|---|---|---|
| Remember | Material choice shapes survival | source, process, property, use, repair |
| Recognize | Identify useful materials and dangerous substitutes | field tests, samples, drawings, local names |
| Measure | Track dimensions, ratios, temperature signs, strength, drying, wear | rods, balances, gauges, trial pieces |
| Rebuild | Make containers, tools, shelter parts, cloth, paper, mortar, metal edges | workshops, kilns, looms, forges, storage |
| Teach | Train makers, repairers, conservators, inspectors, and tool stewards | apprenticeships, exercises, failure catalogs |

Recovery fails when artifacts are copied without understanding material
behavior.

## Layer 1: Sources and Field Tests

Material recovery begins with recognizing what is available.

| Material | Field Clue | Quick Test | Recovery Use |
|---|---|---|---|
| Clay | sticky fine soil, river deposits | coil, dry, fire trial | pots, brick, seal, tile |
| Wood | grain, hardness, resin, straightness | split, bend, dry sample | shelter, tools, fuel |
| Fiber | long stems, bark, hair, leaf | twist, wet, pull | rope, cloth, baskets |
| Stone | fracture, hardness, bedding | scratch, strike, weather | tools, walls, grinding |
| Sand / silica | clean grains, river or dune | melt trial if fuel allows | glass, mortar, filtration |
| Limestone | pale rock, fossils | acid fizz, burn trial | lime, mortar, sanitation |
| Ore | heavy, colored, magnetic, staining | roast/smelt trial | metal tools, pigments |
| Hide / bone | animal byproducts | scrape, dry, boil | leather, glue, tools |

Field-test rule:

```
small sample, controlled process, recorded result, only then scale
```

Bulk processing before testing wastes fuel, labor, and sometimes lives.

## Layer 2: Fire, Heat, Drying, and Kilns

Heat is the first great transformer.

```
wet -> dry -> char -> fire -> sinter -> melt
```

| Heat Process | Material Change | Failure Signs |
|---|---|---|
| Drying | removes water | cracking, mold, warping |
| Smoking / charring | preserves or hardens surface | brittleness, incomplete treatment |
| Firing clay | makes ceramic | bloating, underfire, thermal shock |
| Burning lime | limestone becomes quicklime | underburn, dangerous slaking |
| Charcoal making | wood becomes hot clean fuel | ash, smoke loss, low yield |
| Smelting | ore becomes metal | slag problems, toxic fumes, poor temperature |
| Glass melt | sand fluxes into glass | fuel demand, cracking, impurities |

Heat rule:

```
temperature + time + atmosphere + cooling rate = result
```

Do not preserve recipes without signs of correct heat and failure.

## Layer 3: Containers, Storage, and Clean Surfaces

Containers are civilization multipliers.

| Container Type | Material Path | Use |
|---|---|---|
| Basket | fiber, reed, bark | dry goods, carrying |
| Pot | clay, temper, firing | water, grain, cooking |
| Barrel / box | wood, joinery, seal | transport, storage |
| Skin / leather bag | hide, tanning, stitching | water, tools, bellows |
| Glass vessel | silica, flux, high heat | medicine, observation, sealed storage |
| Metal pot | smelted or worked metal | heat, durability |
| Paper envelope / label | fiber sheet | seed, records, identification |

Storage rule:

```
dry for dry goods, sealed for pests, clean for medicine, labeled for memory
```

Bad containers turn food, seed, medicine, and records into waste.

## Layer 4: Fiber, Cloth, Rope, and Flexible Strength

Fiber turns plants and animals into portable tension.

```
fiber -> twist -> cord -> rope / thread -> textile / net / seam
```

| Fiber Product | Recovery Use | Failure Sign |
|---|---|---|
| Cordage | tying, traps, shelter, transport | fray, rot, weak splice |
| Rope | lifting, hauling, wells, boats | hidden wear, moisture damage |
| Thread | sewing, repair, wound dressing support | breakage, contamination |
| Cloth | clothing, filters, bandages, sails | mold, tearing, poor weave |
| Net | fishing, storage, carrying | knot failure, wrong mesh |
| Felt / mat | insulation, bedding, roofing | pests, moisture |

Fiber rule:

```
keep clean, dry when stored, inspected under load, and repaired early
```

Rope and cloth are safety-critical materials, not soft extras.

---

## Layer 5: Wood, Stone, Metal, and Tool Edges

Recovery depends on edges, handles, joints, and durable work surfaces.

| Tool Material | Strength | Weakness | Use |
|---|---|---|---|
| Stone | sharp fracture, grinding surface | brittle, hard to shape | cutting, milling, striking |
| Wood | light, workable, resilient | rot, fire, grain weakness | handles, frames, shelter |
| Bone / horn | tough, small tools | variable, biological decay | needles, scrapers, fittings |
| Copper / bronze | workable, castable | soft vs steel, ore limits | vessels, fittings, tools |
| Iron / steel | strong edge, structure | rust, smelting skill | knives, axes, nails, machines |

Tool-edge rule:

```
hard enough to cut, tough enough not to shatter, shaped for sharpening
```

A tool that cannot be maintained is a consumable, not a recovered capability.

## Layer 6: Repair, Reuse, and Standards

Repair is material literacy under pressure.

```
inspect -> diagnose material failure -> stabilize -> repair -> test -> record
```

| Failure | Repair Logic |
|---|---|
| Tear | patch beyond damaged area; distribute load |
| Crack | stop propagation; clamp, bind, fill, or replace |
| Rot | remove moisture source; replace compromised material |
| Rust | clean, dry, oil, isolate, replace if section lost |
| Loose joint | understand load path before tightening |
| Dull edge | sharpen to correct angle; do not overheat |
| Leaking vessel | identify crack, seal, refire, patch, or retire |

Standardization rule:

```
common sizes + known grades + tolerances + labels = repairable systems
```

Without standards, every repair becomes custom archaeology.

## Cargo-Cult Traps

| Trap | Why It Fails | Recovery Countermeasure |
|---|---|---|
| Copy object shape | ignores material, grain, heat, and load | preserve property tests and process variables |
| Scale before testing | wastes scarce fuel and labor | trial pieces first |
| Fire without ventilation | poisoning, burns, explosion | workshop layout and safety practice |
| Strong-looking joint | hidden bad load path | test and inspect under use |
| Disposable mindset | consumes scarce material | repair, reuse, standardize |
| Unlabeled containers | medicine, seed, and chemicals confused | label material, contents, date, hazard |
| Unknown alloy or clay | unpredictable failure | sample, test, record, segregate |
| Tool without sharpening path | capability decays | preserve abrasives, angles, and exercises |

## Practical Reconstruction Sequence

```
1. survey local materials and make sample library
2. establish safe fire, drying, charcoal, and kiln practices
3. make containers for water, food, seed, medicine, and records
4. produce cordage, cloth, mats, and repair textiles
5. make wood handles, frames, shelters, and joinery samples
6. fire clay vessels, brick, tile, and sanitary ware
7. burn lime and make mortar where resources allow
8. recover metal edges and fasteners before complex machines
9. standardize sizes for containers, fittings, handles, and fasteners
10. teach repair as a first-class craft
```

Each material record should include:

| Field | Why |
|---|---|
| Source location | reproducibility |
| Preparation | process control |
| Ratios / dimensions | repeatability |
| Heat / drying signs | quality |
| Test result | suitability |
| Failure mode | safety |
| Repair method | continuity |

## Decision Cheat Sheet

| If you need to... | Start With | Key Caveat |
|---|---|---|
| Rebuild making capacity | Survey local clay, wood, fiber, stone, lime, ore, fuel, and binders | Local materials decide the feasible path |
| Choose a material | Match property, use, environment, repair path, and available process | Composition alone is not performance |
| Make containers | Select material by contents: water, dry food, medicine, seed, records, heat | Bad containers destroy what they protect |
| Recover heat processes | Control temperature, time, atmosphere, fuel, ventilation, and cooling | Fire transforms and kills |
| Make rope or cloth | Test fiber, twist, weave, clean, dry, and inspect under load | Flexible materials fail silently when neglected |
| Repair an object | Diagnose failure mode before patching | Repair without load-path understanding can be dangerous |
| Standardize parts | Define sizes, grades, tolerances, labels, and inspection | Standards trade local freedom for repairability |
| Teach craft | Use sample libraries, exercises, failure examples, and apprenticeships | Written recipes cannot replace material feedback |

## Common Confusion Points

**Material is not just stuff** — Source, structure, process, use, environment,
and repair determine performance.

**Fire is not one operation** — Drying, charring, firing, lime burning, smelting,
and glass melting are different heat regimes.

**Containers are infrastructure** — Water, food, seed, medicine, records, and
tools survive because containers work.

**Repair is knowledge** — A repaired object is a lesson in loads, materials,
failure, and continuity.

**Standardization is a recovery tool** — Common sizes and known grades let
communities repair each other's work.
