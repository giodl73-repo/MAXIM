# Duality — The Shadow Economy of Every Linear Program

## The Big Picture

Every linear program (the **primal**) has a twin (the **dual**). The primal allocates resources to maximize value; the dual prices those resources to minimize the cost of "buying them out." The two are bound by two theorems: **weak duality** (the dual always bounds the primal) and **strong duality** (at optimum, the bounds meet — *for LP, whenever a feasible optimum exists*). The dual variables are **shadow prices**: the marginal value of each constraint.

```
+----------------------------------------------------------------------+
|                   PRIMAL  <---- DUALITY ---->  DUAL                   |
|                                                                      |
|   PRIMAL (the producer)            DUAL (the resource pricer)        |
|   ----------------------           ------------------------          |
|   max  c'x    "max profit"         min  b'y    "min cost to buy out  |
|   s.t. Ax <= b  (m resources)            A'y >= c   all resources"   |
|        x >= 0  (n products)              y >= 0                       |
|                                                                      |
|   x_j = amount of product j        y_i = PRICE of resource i         |
|   b_i = available units of i             (= SHADOW PRICE)            |
|   c_j = profit per unit of j                                         |
|                                                                      |
|        c'x  <=  b'y      <--- WEAK DUALITY (every feasible pair)     |
|        ^                  ^                                          |
|        |                  |                                          |
|   any primal-feasible x   any dual-feasible y                       |
|                                                                      |
|        c'x* = b'y*       <--- STRONG DUALITY (at the optimum, LP)   |
|                               the gap closes to ZERO                 |
+----------------------------------------------------------------------+
```

**Read this as an economy**: the primal runs a factory, the dual is an accountant assigning an internal price to each raw material such that no product is worth producing beyond its resource cost. At equilibrium the factory's profit equals the total imputed value of its resources. That equality is strong duality.

## Layer 1: Constructing the Dual Mechanically

The dual is not invented per problem — it is generated by a fixed recipe. For the standard primal

$$\max\; c^\top x \quad \text{s.t.}\quad Ax \le b,\; x \ge 0,$$

the dual is

$$\min\; b^\top y \quad \text{s.t.}\quad A^\top y \ge c,\; y \ge 0.$$

```
   PRIMAL                          DUAL
   ------                          ----
   max c'x                         min b'y
   m constraints (rows of A)  <->  m variables y (one per constraint)
   n variables x              <->  n constraints (cols of A -> rows of A')
   constraint i  Ax_i <= b_i  <->  variable y_i >= 0
   variable x_j >= 0          <->  constraint (A'y)_j >= c_j
```

### The Transformation Table (memorize this)

For a **maximization** primal, each primal element maps to a dual element:

| Primal (max) | Dual (min) |
|--------------|------------|
| constraint $\le b_i$ | variable $y_i \ge 0$ |
| constraint $\ge b_i$ | variable $y_i \le 0$ |
| constraint $= b_i$ | variable $y_i$ free |
| variable $x_j \ge 0$ | constraint $(A^\top y)_j \ge c_j$ |
| variable $x_j \le 0$ | constraint $(A^\top y)_j \le c_j$ |
| variable $x_j$ free | constraint $(A^\top y)_j = c_j$ |
| objective coeff $c_j$ | dual RHS |
| RHS $b_i$ | dual objective coeff |

**The symmetry**: the dual of the dual is the primal. Duality is an involution. (Easiest to verify by converting the dual to standard form and re-applying the recipe.)

```
   PRIMAL --dualize--> DUAL --dualize--> PRIMAL   (you end up back home)
```

## Layer 2: Weak Duality

**Theorem (Weak Duality).** If $x$ is primal-feasible ($Ax \le b$, $x \ge 0$) and $y$ is dual-feasible ($A^\top y \ge c$, $y \ge 0$), then
$$c^\top x \;\le\; y^\top A x \;\le\; b^\top y.$$
*No hypotheses beyond feasibility of both points.*

```
   PROOF (one line each step):
   c'x  <=  (A'y)'x   because A'y >= c and x >= 0   (dual feas + primal sign)
        =   y'(Ax)
        <=  y'b        because Ax <= b and y >= 0   (primal feas + dual sign)
        =   b'y.
```

```
   THE NUMBER LINE OF WEAK DUALITY:

   primal objective values          dual objective values
   (all feasible c'x)               (all feasible b'y)
   ----------------|---------gap--------|------------------>
                  c'x*               b'y*
              (primal opt)        (dual opt)
       <----- max pushes right    min pushes left ----->
```

**Three immediate corollaries** (these are why duality is operationally useful):

| Corollary | Statement | Use |
|-----------|-----------|-----|
| Bounding | Any dual-feasible $y$ gives an upper bound $b^\top y$ on the primal max | Certificates in branch & bound (file 03) |
| Optimality certificate | If $c^\top \hat x = b^\top \hat y$ for feasible $\hat x, \hat y$, both are optimal | Prove optimality without exhaustive search |
| Unbounded ⟹ infeasible | If primal is unbounded, dual is infeasible (and vice versa) | Diagnose model errors |

## Layer 3: Strong Duality — State the Hypotheses Carefully

**Theorem (Strong Duality for LP).** If the primal LP has a finite optimal value, then the dual also has a finite optimal value, and the two optimal values are **equal**: $c^\top x^* = b^\top y^*$.

Equivalently and more carefully, **exactly one** of the four combinations below holds (LP duality is *not* symmetric about infeasibility — read the table):

```
+-------------------------------------------------------------------+
|                    |   DUAL feasible      |   DUAL infeasible      |
|--------------------+----------------------+------------------------|
|  PRIMAL feasible   | both have optimal    | primal UNBOUNDED       |
|                    | finite values, EQUAL |                        |
|--------------------+----------------------+------------------------|
|  PRIMAL infeasible | dual UNBOUNDED       | both infeasible        |
|                    |                      | (possible!)            |
+-------------------------------------------------------------------+
```

**Critical precision points** (commonly stated wrong):

1. Strong duality for LP holds **whenever the primal has a finite optimum** — no constraint qualification is needed (unlike nonlinear programming, file 05). Finiteness (equivalently, both primal and dual feasible) is the only hypothesis.
2. It is **possible for both primal and dual to be infeasible** simultaneously (bottom-right cell). So "primal infeasible ⟹ dual unbounded" is **false** in general — you also need the dual to be feasible.
3. The zero-duality-gap property is special to LP (and convex programs with constraint qualification). **General nonconvex problems can have a strictly positive duality gap.**

**Proof sketch** (the honest version): strong duality follows from a separating-hyperplane / Farkas argument, or constructively from the simplex method. When simplex terminates optimally with basis $B$, set $y^\top = c_B^\top B^{-1}$. The optimality test (all reduced costs $\le 0$) is exactly $A^\top y \ge c$ — dual feasibility — and $b^\top y = c_B^\top B^{-1} b = c_B^\top x_B = c^\top x^*$. So simplex hands you the optimal dual for free.

### Farkas' Lemma — the engine underneath

**Lemma (Farkas).** Exactly one of the following holds:
- (I) $\exists\, x \ge 0$ with $Ax = b$; or
- (II) $\exists\, y$ with $A^\top y \ge 0$ and $b^\top y < 0$.

```
   GEOMETRIC READING:
   Either b is INSIDE the cone generated by columns of A   (system solvable)
   ... OR a hyperplane SEPARATES b from that cone           (a certificate)
   -- never both, never neither.
```

Farkas is a *theorem of the alternative*: it gives a **certificate of infeasibility**. This is the source of strong duality and the reason an LP solver can *prove* infeasibility, not merely fail to find a solution.

## Layer 4: Complementary Slackness

The sharpest practical tool. It links *which constraints are tight* to *which dual prices are nonzero*.

**Theorem (Complementary Slackness).** Let $x$ be primal-feasible and $y$ dual-feasible. They are **both optimal** if and only if:

$$y_i \,(b_i - (Ax)_i) = 0 \;\; \forall i \qquad\text{and}\qquad x_j\,((A^\top y)_j - c_j) = 0 \;\; \forall j.$$

```
+----------------------------------------------------------------------+
|             COMPLEMENTARY SLACKNESS, IN WORDS                        |
|                                                                      |
|  For each constraint i:                                              |
|     slack > 0 (resource i UNUSED)   =>   y_i = 0  (price zero)       |
|     y_i > 0 (resource i is PRICED)  =>   constraint i is TIGHT       |
|                                                                      |
|  For each variable j:                                                |
|     x_j > 0 (we PRODUCE product j)  =>   its dual constraint TIGHT   |
|     dual constraint slack > 0       =>   x_j = 0 (don't produce j)   |
|                                                                      |
|  "You never pay for what you don't use, and you never use            |
|   what isn't worth its imputed cost."                               |
+----------------------------------------------------------------------+
```

**Why it matters**: complementary slackness is how you (a) verify a candidate solution is optimal by hand, (b) recover the primal solution from the dual (or vice versa), and (c) understand *which* resources are the binding bottlenecks.

```
   USING CS TO CHECK OPTIMALITY:

   Given candidate x* :
   1. Identify tight constraints (slack = 0) -> their y_i may be > 0
      and non-tight constraints -> force y_i = 0.
   2. For each x_j* > 0, force its dual constraint to equality.
   3. Solve the resulting linear system for y.
   4. If that y is dual-FEASIBLE (A'y >= c, y >= 0), then by CS
      x* and y are BOTH OPTIMAL. Otherwise x* was not optimal.
```

## Layer 5: Shadow Prices and Sensitivity Analysis

The optimal dual variable $y_i^*$ is the **shadow price** of constraint $i$: the rate of change of the optimal objective per unit change in $b_i$.

$$y_i^* = \frac{\partial z^*}{\partial b_i} \qquad\text{(within the range where the optimal basis stays optimal)}.$$

```
   OPTIMAL OBJECTIVE z* AS A FUNCTION OF RHS b_i:

   z*(b_i)
     |                      slope = y_i (next basis)
     |                  ___/
     |              ___/  <- breakpoint: basis changes here
     |          ___/  slope = y_i* (current shadow price)
     |      ___/
     |  ___/
     +------------------------------------ b_i
        |---- validity range of current basis ----|

   z*(b) is PIECEWISE LINEAR and CONCAVE in b (for a max LP).
   Shadow price = slope of the current piece.
```

| Sensitivity question | Answer source |
|----------------------|---------------|
| "What is one more unit of resource $i$ worth?" | Shadow price $y_i^*$ |
| "Over what RHS range is $y_i^*$ valid?" | RHS ranging — interval where optimal basis $B$ stays feasible |
| "How much can $c_j$ change before the solution shifts?" | Objective (cost) ranging — interval keeping reduced costs $\le 0$ |
| "Should I add a new product/column?" | Pricing: is its reduced cost $c_j - y^\top A_j > 0$? (column generation) |

**Caveats stated precisely**:
- The shadow price is a **one-sided derivative** at a breakpoint and is **non-unique under primal degeneracy** (left and right slopes differ).
- It is valid only **within the validity range** of the current optimal basis; beyond a breakpoint the basis changes and the price jumps.
- $z^*(b)$ is concave (for max) — diminishing returns — so shadow prices are non-increasing as you relax a resource.

**Bridge — column generation**: pricing out a not-yet-included column using the dual $y$ is the foundation of **column generation** and **Dantzig–Wolfe decomposition**, the workhorses for huge structured LPs (e.g., cutting-stock, crew scheduling). You solve a "pricing subproblem" to find a column with positive reduced cost.

## Duality Across the Library

Duality is not an LP curiosity; it recurs everywhere:

```
+----------------------------------------------------------------------+
|  WHERE DUALITY SHOWS UP                                             |
|                                                                      |
|  LP duality            ----  this file                              |
|  Max-flow = Min-cut    ----  network flows (file 04), a duality thm  |
|  KKT conditions        ----  convex optimization (file 05),         |
|                              the nonlinear generalization           |
|  Minimax theorem       ----  game-theory/: von Neumann's theorem    |
|                              IS LP strong duality for zero-sum games |
|  SVM dual              ----  machine-learning-theory/: the kernel    |
|                              trick lives in the dual                |
|  Lagrangian duality    ----  the unifying frame; LP duality is the   |
|                              linear special case                    |
+----------------------------------------------------------------------+
```

The **Lagrangian** view unifies all of these: form $L(x,y) = c^\top x + y^\top(b - Ax)$, and the dual function is $g(y) = \max_x L(x,y)$. Weak duality is $\min_y g(y) \ge \max_x \min_y L$. For LP and convex problems (with constraint qualification) the inequality becomes equality — strong duality. File 05 develops this for the nonlinear case.

## Old World → Duality Bridges

| You already know | Dual analogue |
|------------------|---------------|
| Internal cost accounting / transfer pricing | Shadow prices are exactly imputed internal prices of resources |
| "What's the bottleneck?" in capacity planning | Constraints with $y_i^* > 0$ are the active bottlenecks |
| Marginal cost / marginal value reasoning | $y_i^* = \partial z^*/\partial b_i$ is a marginal value |
| Certificate of infeasibility (e.g., UNSAT core) | Farkas certificate: a $y$ proving no feasible $x$ exists |
| Lower/upper bounds in branch & bound | Dual feasible point = valid bound (file 03) |
| Lagrange multipliers from calculus | Dual variables ARE Lagrange multipliers |

The unifying idea for a systems leader: **the dual tells you what your constraints are worth.** If you can only act on one constraint, act on the one with the highest shadow price — that's the bottleneck whose relaxation yields the most.

## Common Confusion Points

### "Does strong duality always hold?"

For **LP**: it holds whenever the primal has a finite optimum (equivalently, primal and dual both feasible) — **no constraint qualification required**. For general **convex** problems it requires a constraint qualification (e.g., **Slater's condition**: a strictly feasible point exists). For **nonconvex** problems strong duality can **fail** — there can be a strictly positive duality gap. Always state which regime you're in.

### "Primal infeasible means dual unbounded, right?"

**Not necessarily.** Primal infeasible plus dual *feasible* ⟹ dual unbounded. But **both** primal and dual can be infeasible simultaneously. The four-cell table in Layer 3 is the correct statement; the naive one-liner is wrong.

### "Shadow price = the constraint's RHS coefficient?"

No. The shadow price $y_i^*$ is the *dual variable* — the marginal value of the constraint, not its right-hand side $b_i$. $b_i$ is the available quantity; $y_i^*$ is what one more unit is worth. They appear together in the dual objective $b^\top y$.

### "Is the shadow price unique?"

Not under **degeneracy**. At a degenerate optimal vertex the dual optimum is not unique, so the shadow price is a one-sided derivative and the left/right marginal values differ. Practically: a small increase and a small decrease in $b_i$ can have different per-unit effects. Sensitivity reports give a *range*, not a single number, for this reason.

### "Why does the dual of the dual return the primal?"

Because the dualization recipe is an involution: dualize, convert back to standard form, dualize again, and the transformation table maps every element back to its origin. This is structural, not coincidental — it reflects the symmetric way constraints and variables swap roles.

### "Complementary slackness vs. strong duality — are they the same?"

They are equivalent characterizations of optimality (given feasibility). Strong duality says the objective values meet; complementary slackness says the term-by-term products vanish. The link: $0 = b^\top y - c^\top x = y^\top(\text{slacks}) + x^\top(\text{dual slacks})$, and since all terms are nonnegative at feasibility, the total is zero iff each term is zero — which is exactly complementary slackness.
