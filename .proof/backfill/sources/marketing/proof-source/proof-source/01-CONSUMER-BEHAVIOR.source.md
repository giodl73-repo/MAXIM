# Consumer Behavior

## The Big Picture

Consumer behavior is the study of how individuals select, buy, use, and dispose
of offerings — and *why*. It is the customer-side model that everything else in
marketing acts on. The landscape: external and internal inputs flow into a
decision process, which produces a choice, which feeds back as experience.

```
+-------------------------------------------------------------------------+
|                     THE CONSUMER BEHAVIOR SYSTEM                        |
|                                                                         |
|  INPUTS                  PROCESSING                  OUTPUTS            |
|  ------                  ----------                  -------            |
|                                                                         |
|  EXTERNAL                +--------------------+      CHOICE             |
|   culture, social   ---> |  DECISION PROCESS  | ---> buy / not          |
|   class, family,         |  1 need recognition|      which brand        |
|   reference groups       |  2 info search     |      how much           |
|                          |  3 evaluation      |          |              |
|  INTERNAL                |  4 purchase        |          v              |
|   motivation, percep-    |  5 post-purchase   |      EXPERIENCE         |
|   tion, learning,   ---> +--------------------+      satisfaction,      |
|   memory, attitudes,            ^                    loyalty, word-     |
|   personality                   |                    of-mouth           |
|                                 +---- feedback loop ------+             |
|                                                                         |
|  MODERATED BY: involvement level + perceived risk + time pressure       |
+-------------------------------------------------------------------------+
```

**Read left-to-right with a feedback loop**: inputs feed a decision process;
the outcome becomes an input (memory/attitude) for next time. The whole thing is
moderated by how much the buyer *cares* (involvement) and how much can go *wrong*
(perceived risk).

This guide bridges directly to `behavioral-economics/` — that field is the
rigorous account of *where the decision process deviates from rational choice*.
Here we map the process; there you get the biases.

## Needs and Motivation

A purchase starts with a **need** — a gap between a desired and an actual state —
that becomes a **motive** when it is aroused enough to drive action. The most
cited (and most over-applied) organizing model is **Maslow's hierarchy of needs**.

```
+-----------------------------------------------------------------+
|                MASLOW'S HIERARCHY (1943)                        |
|                                                                 |
|                       .-----------.                             |
|                      / SELF-ACTUAL \   growth, mastery,         |
|                     /  -IZATION     \  "be all you can be"      |
|                    .-----------------.                          |
|                   /   ESTEEM          \  status, recognition    |
|                  .---------------------.                        |
|                 /  BELONGING / SOCIAL   \  love, friendship,    |
|                .-------------------------.  affiliation         |
|               /     SAFETY                \  security, health,  |
|              .-----------------------------.  stability         |
|             /   PHYSIOLOGICAL               \  food, water,     |
|            .-------------------------------- .  sleep, shelter  |
|                                                                 |
|  Claim: lower needs dominate until met; higher needs then       |
|  motivate. (Empirically the strict ordering is weak — treat     |
|  it as a vocabulary for need TYPES, not a strict ladder.)       |
+-----------------------------------------------------------------+
```

Marketers use Maslow to ask *which need a product serves*. The same object can be
sold against different levels: a watch as timekeeping (physiological/functional),
as safety (durable, reliable), or as esteem (a luxury signal). The lever you pull
in positioning (`02`) is the need you claim.

| Need type | What the buyer is really buying | Example pitch |
|---|---|---|
| **Functional** | The job done | "Charges in 20 minutes" |
| **Social/belonging** | Identity, affiliation | "Join the community" |
| **Esteem/status** | Signal to others | "The professional's choice" |
| **Hedonic** | Pleasure, experience | "Indulge yourself" |
| **Self-actualization** | Growth, meaning | "Become your best self" |

A second useful split, from McGuire and others, is **utilitarian vs hedonic**
motives — *should I* (functional, guilt-reducing) vs *want to* (pleasure,
indulgence). Most purchases blend both; the mix shifts the message.

## The Consumer Decision Process

The classic five-stage model (Engel-Kollat-Blackwell) is the spine. Treat it as
a **pipeline** — stages can be skipped, looped, or compressed to near-zero for
habitual buys.

```
+------------------------------------------------------------------+
|              FIVE-STAGE DECISION PROCESS                         |
|                                                                  |
|  1. NEED        Internal trigger (hunger) or external            |
|     RECOGNITION (an ad, a friend). Gap is felt.                  |
|        |                                                         |
|        v                                                         |
|  2. INFO        Internal (memory) then external (search, ask,    |
|     SEARCH      reviews). Builds the CONSIDERATION SET.          |
|        |                                                         |
|        v                                                         |
|  3. EVALUATION  Compare the consideration set on ATTRIBUTES,     |
|     OF ALTS     weighted by importance. (Compensatory or not.)   |
|        |                                                         |
|        v                                                         |
|  4. PURCHASE    Intention -> action. Can be derailed by stock-   |
|     DECISION    outs, friction, last-minute risk, others' views. |
|        |                                                         |
|        v                                                         |
|  5. POST-       Confirm vs disconfirm expectations. Satisfac-    |
|     PURCHASE    tion, dissonance, loyalty, word-of-mouth.        |
+------------------------------------------------------------------+
```

### The consideration set funnels down

Search does not produce "all options" — it produces a small **consideration set**.
Winning is often about *getting into the set*, not beating every rival.

```
  TOTAL SET          all brands that exist
     |  (awareness)
  AWARENESS SET      brands the buyer knows
     |  (recall/fit)
  CONSIDERATION SET  3-5 brands actively weighed   <-- the real battle
     |  (evaluation)
  CHOICE SET         the finalists
     |  (decision)
  PURCHASE           the one chosen
```

### Evaluation rules: compensatory vs non-compensatory

How buyers combine attributes matters for how you position.

| Rule | Logic | Implication for you |
|---|---|---|
| **Compensatory** | Weighted sum; a strength offsets a weakness | Win on *total* score; push your strong attribute hard |
| **Conjunctive** | Must clear a threshold on *every* key attribute | A single failing attribute eliminates you — fix table stakes |
| **Lexicographic** | Rank attributes; decide on the top one, tie-break down | Win the #1 attribute or be invisible |
| **Elimination by aspects** | Drop options failing successive cutoffs | Survive each cutoff filter |

This is **multi-criteria decision analysis** with human weights. The bridge: it's
a ranking function with feature weights — and like any ranking function, the
*choice of rule* changes the winner even with the same data.

## Involvement and Perceived Risk

Not all decisions get the full five stages. **Involvement** — the personal
relevance and stakes — determines how much processing happens. This produces four
distinct buying-behavior modes (Assael).

```
+------------------------------------------------------------------+
|                  BUYING-BEHAVIOR TYPES                           |
|                                                                  |
|                   |  HIGH involvement   |  LOW involvement       |
|  -----------------+---------------------+----------------------- |
|  SIGNIFICANT      |  COMPLEX buying     |  VARIETY-SEEKING       |
|  brand            |  (car, house):      |  (snacks):             |
|  DIFFERENCES      |  full search +      |  switch for novelty,   |
|                   |  evaluation         |  not dissatisfaction   |
|  -----------------+---------------------+----------------------- |
|  FEW              |  DISSONANCE-        |  HABITUAL buying       |
|  brand            |  REDUCING (carpet): |  (salt):               |
|  DIFFERENCES      |  buy, then justify  |  no search, no         |
|                   |  to reduce regret   |  evaluation, autopilot |
+------------------------------------------------------------------+
```

**Perceived risk** raises involvement. Its components: financial, functional
(will it work), physical (safety), social (what others think), psychological
(self-image), and time. Marketers *reduce* perceived risk with warranties, free
trials, reviews, social proof, and money-back guarantees — each one a friction
removed from stage 4.

```
OLD WORLD                          CONSUMER ANALOG
-----------------------------      -------------------------------------
Reducing deployment risk           Reducing purchase risk
  canary, rollback, staging          free trial, money-back, reviews
"Reduce friction in the flow"      Reduce friction at the purchase step
SLA / guarantees to the customer   Warranties / guarantees reduce risk
```

## Behavioral Influences: Perception, Learning, Attitudes

Inside the "INTERNAL" box are the psychological mechanisms. Three matter most.

### Perception

Buyers do not receive stimuli neutrally. **Selective attention** (most ads are
filtered out), **selective distortion** (fitting messages to prior beliefs), and
**selective retention** (remembering what supports existing attitudes) mean your
message competes for limited cognitive bandwidth.

```
  1000s of stimuli/day
        |  selective ATTENTION (filter)
        v
  the few that get noticed
        |  selective DISTORTION (interpret to fit beliefs)
        v
  the interpreted message
        |  selective RETENTION (remember the congenial bits)
        v
  what actually persists in memory
```

This is lossy compression with a prior. It is *why* repetition, distinctiveness,
and consistency matter in advertising (`05`) — you are fighting three filters.

### Learning

Behavior shaped by experience. Two mechanisms marketers exploit:
**classical conditioning** (pairing a brand with a positive stimulus until the
brand alone evokes the feeling) and **operant/instrumental conditioning**
(rewarding desired behavior — loyalty points, variable rewards). Variable-ratio
reward schedules — the engine of habit loops and streaks — are detailed in
`behavioral-economics/10-APPLICATIONS-PRODUCT-UX.md`.

### Attitudes

A learned predisposition to respond consistently (favorably or not). The standard
**ABC / tri-component model**:

| Component | What it is | Lever |
|---|---|---|
| **Affective** | Feelings toward the brand | Emotional advertising, aesthetics |
| **Behavioral (conative)** | Intention / tendency to act | Trials, samples, low-commitment first steps |
| **Cognitive** | Beliefs, attributes, knowledge | Information, comparisons, specs |

Changing an attitude means moving one component and letting the others follow
(or attacking all three). The order you target depends on involvement: high-
involvement buyers go cognition -> affect -> behavior (learn, feel, do);
low-involvement often go behavior -> affect (try it, then form a feeling).

## The Bridge to Behavioral Economics

The five-stage model assumes a deliberative processor. Real buyers are the
*bounded, biased* agents of behavioral economics. Map the deviations onto the
process so you know where they bite.

```
+-----------------------------------------------------------------+
|  DECISION STAGE        WHERE BEHAVIORAL BIAS DISTORTS IT        |
|  --------------        -----------------------------------------|
|  Need recognition      Framing: how the gap is presented        |
|                        creates or suppresses the felt need      |
|                                                                 |
|  Info search           Confirmation bias; availability          |
|                        heuristic (recent/vivid = "common")      |
|                                                                 |
|  Evaluation            Anchoring (first price seen); the        |
|                        DECOY effect; loss aversion (~2x)        |
|                                                                 |
|  Purchase              Default effect; present bias             |
|                        (buy-now-pay-later); choice overload     |
|                                                                 |
|  Post-purchase         Cognitive dissonance; endowment effect   |
|                        (now that I own it, I value it more)     |
+-----------------------------------------------------------------+
```

| Marketing term | Behavioral-economics theory | Where to read it |
|---|---|---|
| Reference price | Reference-dependence, prospect theory | `behavioral-economics/02` |
| Decoy / compromise option | Context effects, choice architecture | `behavioral-economics/07` |
| Mental "budget" for a category | Mental accounting | `behavioral-economics/04` |
| Default plan / opt-out | Default effect, nudges | `behavioral-economics/07` |
| Post-purchase rationalization | Cognitive dissonance | `behavioral-economics/03` |

The discipline split: **behavioral economics asks "why is the human irrational
here, and is it systematic?" Marketing asks "given that, what do I build and
say?"** Same phenomena, different verb — explain vs act.

## Decision Cheat Sheet

| Situation | What to do |
|---|---|
| Launching a new, unfamiliar product | Lower perceived risk: trials, guarantees, reviews, social proof |
| Buyer ignores your ads | Fighting selective attention — increase distinctiveness + repetition |
| You're not in the consideration set | Awareness and recall problem (`05`), not a feature problem |
| High-involvement category (B2B, big-ticket) | Provide deep info; expect full 5-stage process; support evaluation |
| Low-involvement / habitual category | Win on availability, distinctiveness, and habit, not persuasion |
| Customers buy then regret | Post-purchase dissonance — reassure after the sale (onboarding, email) |
| Need to change brand perception | Identify which ABC component is weak; target it, let others follow |
| Want repeat purchase | Operant conditioning: reward loops, loyalty, ensure satisfaction > expectation |

## Common Confusion Points

### "Maslow's hierarchy is a strict ladder"

It is a useful *vocabulary for need types*, not a validated strict sequence.
People pursue esteem while hungry; the ordering is weak empirically. Use it to
name *which need a product serves*, not to predict a fixed progression.

### "More information always helps the buyer choose"

Beyond a point it hurts — **choice overload** and information overload raise
perceived risk and can stall the decision entirely (the jam-study result). For
low-involvement buys, *less* is more; curate the consideration set.

### "Attitude predicts behavior directly"

The attitude-behavior gap is large and well-documented. People hold favorable
attitudes and still don't buy (price, availability, habit, social pressure
intervene at stage 4). Measure *intention* and *behavior* separately from
*attitude* — and trust behavior most.

### "We need to create the need"

Mostly you *surface and channel* a latent need, you rarely create one from
nothing. The realistic lever is *need recognition* (make the gap salient) and
*shaping the consideration set* — not manufacturing demand that has no underlying
motive.

### "Consumer behavior and behavioral economics are the same field"

Heavily overlapping, different center of gravity. Consumer behavior is older,
broader (culture, family, perception, the full process) and applied. Behavioral
economics is the rigorous, often experimental account of *systematic
irrationality* with formal models (prospect theory). Read `01` for the process,
`behavioral-economics/` for the mechanisms.
