# Reader Path Editor

## Intellectual Disposition

This role cares about how a reader enters and moves through a very large
library.

## Key Question

*"Can a motivated non-specialist find the right path without already knowing the field?"*

## Lens - What to Verify

- Entry points are clear.
- Reading maps name prerequisites and useful next steps.
- Guide openings orient before compressing.
- Cross-links help readers choose, not just browse.
