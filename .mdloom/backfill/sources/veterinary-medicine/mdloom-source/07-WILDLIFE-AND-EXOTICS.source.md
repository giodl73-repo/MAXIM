# Wildlife and Exotics — Conservation Medicine and Exotic Species

```
+------------------------------------------------------------------------------+
|              THE WIDENING OF THE PATIENT SET                                 |
|                                                                              |
|   COMPANION (file 05)   ->   EXOTIC PETS   ->   ZOO   ->   FREE-RANGING      |
|   dog, cat, rabbit           reptiles,          megafauna   WILDLIFE         |
|                              birds, fish,        (tiger,     (population is  |
|                              ferrets             elephant)   the patient)    |
|                                                                              |
|   KNOWN BIOLOGY   ----------------------------------->   SPARSE BIOLOGY      |
|   (well-studied)                                         (often inferred     |
|                                                          from related spp.)  |
|                                                                              |
|   INDIVIDUAL VALUE   ------------------------------>   POPULATION /          |
|   (the pet)                                            SPECIES value         |
+------------------------------------------------------------------------------+
```

**Read left to right.** As you move from pets to free-ranging wildlife, two things happen:
the biological knowledge base thins (you may be extrapolating drug doses from a related
species), and the unit of value shifts from the individual to the population or the species'
survival. Conservation medicine treats the *population* and the ecosystem, echoing the herd
logic of file 06 but with biodiversity, not production, as the objective.

**Systems Bridge:** This is operating undocumented, heterogeneous legacy systems at the edge.
Companion practice has a manual (decades of canine/feline data); exotic and wildlife medicine
often has no manual for the exact species, so you reason by homology from the nearest
documented relative (allometric scaling, related-species drug data) and accept higher
uncertainty. The free-ranging tier adds the constraint that you usually cannot observe or
re-handle the node — you get one capture event, so every intervention must be planned for
single-shot execution.

Cross-references: `zoology/`, `animal-phylogeny/`, and `marine-biology/` for the species
substrate; `ecology/` for population context; file 04 for wildlife as disease reservoirs.

## Exotic Pets — Many Phyla, One Clinic

"Exotics" lumps together animals from across the tree of life, unified only by being kept as
pets and being non-traditional. The clinical reality is that each requires its own normal.

```
+------------------------------------------------------------------------------+
|                    EXOTIC PET GROUPS + DOMINANT ISSUE                        |
|                                                                              |
|  GROUP             DOMINANT CLINICAL THEME                                   |
|  -----             ------------------------                                  |
|  Reptiles          HUSBANDRY disease: wrong temp/UVB/humidity (file 02).     |
|  (snakes, lizards,   Metabolic bone disease (no UVB -> no D3 -> no Ca++),    |
|   turtles)           respiratory infection (too cold), dystocia (egg-bound). |
|  Birds             nutritional (all-seed diets -> deficiency), feather-      |
|  (parrots)           plucking (behavioral), air-sac disease, egg-binding,    |
|                      heavy-metal toxicity (chewing on metal cages/toys).     |
|  Fish              WATER QUALITY is medicine: ammonia/nitrite, pH, oxygen,   |
|  (ornamental,        temperature. Most "disease" is a water-chemistry        |
|   koi)               failure; treat the tank, not just the fish.             |
|  Amphibians        skin is a respiratory + osmotic organ -> extremely        |
|  (frogs)             sensitive to water chemistry and toxins; chytrid        |
|                      fungus is a conservation catastrophe (below).           |
|  Small mammals     (covered in file 05: rabbit, ferret, rodents)             |
|  Invertebrates     even honeybees and tarantulas have veterinary needs;      |
|                     bee health (Varroa mite, foulbrood) is agriculturally    |
|                     important for pollination.                               |
+------------------------------------------------------------------------------+
```

The recurring lesson, already met for reptiles and small mammals: in exotics, **the
environment is the medicine**. A "sick" reptile, fish, or amphibian is usually an
environmental-parameter failure (temperature, UVB, water chemistry) before it is a primary
pathogen. The first diagnostic move is to audit the habitat.

### Reptile metabolic bone disease — a clean husbandry chain

```
   No UVB light  ->  no skin synthesis of vitamin D3  ->  no intestinal
   calcium absorption  ->  body pulls Ca++ from bone  ->  soft, deformed,
   fracturing bones (metabolic bone disease).

   FIX: correct UVB lighting + dietary calcium + correct temperature
   (so the animal basks and metabolizes). A lighting problem, not a
   drug problem.
```

### Bird nutritional disease — the all-seed trap

Pet parrots fed all-seed diets develop deficiencies (vitamin A especially) and obesity. The
fix is a balanced/pelleted diet. Birds also suffer heavy-metal (lead, zinc) toxicity from
chewing cage parts and toys — a presentation with neuro and GI signs that has no common
companion-mammal analog.

## Zoo and Megafauna Medicine — Restraint Is the Hard Part

For large, dangerous, or wild zoo animals, the limiting problem is often not diagnosis but
*safely handling the patient at all*. Chemical restraint (immobilization) is its own
specialty.

```
+------------------------------------------------------------------------------+
|                    CHEMICAL RESTRAINT OF MEGAFAUNA                           |
|                                                                              |
|   You cannot ask an elephant to hold still or a tiger to open its mouth.     |
|   Immobilization uses potent agents delivered by dart:                       |
|                                                                              |
|     POTENT OPIOIDS (e.g. etorphine, "M99") -- many THOUSANDS of times        |
|       more potent than morphine. Used to drop large ungulates/megafauna.     |
|       So potent that they are a HUMAN HAZARD: an accidental dart-stick or    |
|       skin exposure can kill the veterinarian -> a reversal agent            |
|       (e.g. naltrexone/diprenorphine) is kept drawn up at all times.         |
|                                                                              |
|     ALPHA-2 AGONISTS (medetomidine, xylazine) + KETAMINE combinations        |
|       for sedation/anesthesia, chosen by species.                            |
|                                                                              |
|   RISKS of immobilizing big animals:                                         |
|     * CAPTURE MYOPATHY: stress + muscle exertion during capture -> muscle    |
|       breakdown (rhabdomyolysis) -> kidney failure, death, sometimes days    |
|       later. A leading cause of capture-related wildlife death.              |
|     * Positional problems: a recumbent elephant/giraffe can suffer from      |
|       its own weight crushing tissue or impairing breathing.                 |
|     * Regurgitation/bloat in immobilized ruminants.                          |
+------------------------------------------------------------------------------+
```

Two facts here are genuinely arresting: the immobilizing opioids are potent enough to kill
the human handler (so the antidote is always ready), and **capture myopathy** — death from the
stress and exertion of capture itself, sometimes days afterward — means the act of catching a
wild animal can be lethal independent of any drug error. Minimizing capture stress is a core
welfare and survival concern, not a nicety.

**Old world -> new world bridge:** A wild-animal capture is a one-shot, high-blast-radius
operation with no rollback — like a risky production migration you get to run exactly once,
under time pressure, where the failure mode can be fatal and the safety system (the reversal
agent) must be staged and tested before you begin. You plan the whole sequence, pre-stage the
abort, and rehearse, because there is no second attempt on a darted rhino.

## Conservation Medicine — The Population Is the Patient

At the wildlife scale, veterinary medicine merges with conservation biology. The objective is
species and ecosystem persistence. Several disease events have become conservation crises.

```
+------------------------------------------------------------------------------+
|              DISEASE AS A CONSERVATION THREAT (real cases)                   |
|                                                                              |
|  CHYTRIDIOMYCOSIS (Batrachochytrium fungus)                                  |
|    A skin fungus driving global AMPHIBIAN declines and extinctions;          |
|    disrupts the frog's skin (its respiratory/osmotic organ). One of the      |
|    most destructive wildlife diseases ever recorded.                         |
|                                                                              |
|  WHITE-NOSE SYNDROME (Pseudogymnoascus fungus)                               |
|    A cold-loving fungus killing hibernating BATS in North America en         |
|    masse -- rouses them from torpor, burning fat reserves to death.          |
|                                                                              |
|  DEVIL FACIAL TUMOUR DISEASE                                                 |
|    A transmissible CANCER (the tumor cells themselves spread by biting)      |
|    devastating wild Tasmanian devils -- a rare contagious cancer.            |
|                                                                              |
|  H5N1 AVIAN INFLUENZA IN WILDLIFE                                            |
|    Now killing wild birds and marine mammals globally, not just poultry --   |
|    a wildlife + One Health crisis (file 04).                                 |
|                                                                              |
|  CHRONIC WASTING DISEASE (prion, file 03) in wild deer/elk -- spreading,     |
|    environmentally persistent, untreatable.                                  |
+------------------------------------------------------------------------------+
```

The chytrid and white-nose cases illustrate why conservation medicine needs ecology: the
pathogen interacts with the host's physiology (frog skin, bat torpor) and environment (cool,
damp) in ways you cannot understand from clinical medicine alone. Devil facial tumour disease
is a biological oddity worth knowing — an actual *transmissible cancer*, where the tumor cell
line itself is the infectious agent passed by biting.

### Tools of conservation medicine

```
   * Population health surveillance (sentinel sampling, necropsy of found dead).
   * Disease screening before TRANSLOCATION (moving animals can move pathogens
     -- a hard-won lesson; quarantine + testing first).
   * Vaccination of wild populations (e.g. ORAL RABIES VACCINE in baits
     dropped for foxes/raccoons -- vaccinating wildlife to protect both
     wildlife and humans; a One Health intervention, file 04).
   * Captive breeding + genetic management (avoiding inbreeding depression).
   * Habitat + environmental management (the ecology side of the triad).
```

Oral rabies vaccination is a standout success: distributing vaccine-laced baits to immunize
wild reservoir species (foxes, raccoons) has pushed back wildlife rabies across regions — a
literal application of "patch the reservoir" (file 04) to free-ranging animals.

## Aquaculture and Aquatic Medicine — Water Is the Patient

Fish medicine deserves its own note because the *medium* is the dominant variable. The water
is simultaneously the fish's environment, respiratory medium, and toilet.

```
   FIRST DIAGNOSTIC: TEST THE WATER.
     * Ammonia / nitrite (from waste; toxic; the nitrogen cycle must be
       established by beneficial bacteria in the filter).
     * Dissolved oxygen, pH, temperature, salinity.
   A huge fraction of "fish disease" is water-quality failure; correcting the
   chemistry resolves it. Only then look for pathogens (Ich protozoa, fin rot,
   columnaris, viral diseases) and parasites (sea lice in salmon farming -- a
   major economic + welfare issue).
```

This is the same "husbandry is medicine" principle met for reptiles and exotics, taken to its
extreme: you cannot separate the fish from its water, so you treat the system.

## Decision Cheat Sheet

| Presentation | First move / suspicion |
|--------------|------------------------|
| Sick reptile of any kind | Audit husbandry: temperature gradient, UVB, humidity |
| Lizard with soft/deformed bones | Metabolic bone disease (no UVB -> no D3 -> no calcium) |
| Pet parrot, poor feathers, on all-seed diet | Nutritional deficiency (vitamin A); correct diet |
| Parrot with neuro/GI signs, chews cage | Heavy-metal (lead/zinc) toxicity |
| Sick ornamental fish | Test the water first (ammonia/nitrite/O2/pH) |
| Immobilizing megafauna | Stage the opioid reversal agent for the HUMAN; minimize capture stress |
| Wild animal dies days after capture | Capture myopathy (stress rhabdomyolysis) |
| Mass amphibian die-off | Chytrid fungus — conservation emergency |
| Mass hibernating-bat deaths | White-nose syndrome |
| Protecting humans from wildlife rabies | Oral rabies vaccine baits for the reservoir species |

## Common Confusion Points

### "Exotic medicine is just regular medicine on unusual animals"

For many exotic species there is no species-specific manual; doses and norms are extrapolated
from related species with real uncertainty. And the dominant disease driver is usually
husbandry (temperature, UVB, water chemistry), not a primary pathogen. The mindset is closer
to operating an undocumented system than to following a clinical protocol.

### "You just sedate a zoo animal like a big dog"

Megafauna immobilization uses ultra-potent opioids that are lethal to the human handler, must
have reversal agents staged, and carries the risk of capture myopathy — death from the stress
of capture itself. It is a planned, single-shot, high-risk operation, not routine sedation.

### "Wildlife disease doesn't affect people or pets"

Wildlife are reservoirs (rabies, plague, Lyme, H5N1) and the source of most emerging human
diseases (file 04). Conservation medicine and human health are coupled — which is exactly why
interventions like oral rabies baiting of wildlife protect humans too.

### "If the fish is sick, medicate the fish"

In aquatic medicine the water is the patient. Most fish disease is a water-chemistry failure
(ammonia, nitrite, oxygen, pH, temperature); dosing the fish without fixing the system fails.
The toolkit for actually dosing any of these animals — and why doses differ so wildly across
species — is the subject of `08-VETERINARY-PHARM-AND-SURGERY.md`.
