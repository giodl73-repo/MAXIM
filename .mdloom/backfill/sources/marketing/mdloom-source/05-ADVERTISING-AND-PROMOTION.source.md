# Advertising and Promotion

## The Big Picture

This is the **Promotion** P: how the firm communicates value and persuades. The
modern frame is **Integrated Marketing Communications (IMC)** — coordinating every
message so they reinforce one coherent positioning. The landscape runs from
objective, through the mix of tools, through creative and media, to the message
that lands.

```
+-------------------------------------------------------------------------+
|              INTEGRATED MARKETING COMMUNICATIONS (IMC)                  |
|                                                                         |
|  OBJECTIVE        Build awareness / shift attitude / drive action       |
|  (tied to the     (which funnel stage am I moving?)                     |
|   funnel stage)        |                                                |
|                        v                                                |
|  THE PROMOTION    .----------. .----------. .----------. .-----------.  |
|  MIX (tools)      |ADVERTIS- | |  SALES   | |  PUBLIC  | | PERSONAL  |  |
|                   |  ING     | |PROMOTION | |RELATIONS | |  SELLING  |  |
|                   '----------' '----------' '----------' '-----------'  |
|                   | + DIRECT / DIGITAL / SOCIAL (see 08) |              |
|                        |                                                |
|                        v                                                |
|  CREATIVE         The message + execution (what we say, how)            |
|                        |                                                |
|                        v                                                |
|  MEDIA            Reach x Frequency, channels, timing, budget           |
|                        |                                                |
|                        v                                                |
|  RESPONSE         Awareness -> attitude -> behavior (measured, see 09)  |
|                                                                         |
|  IMC PRINCIPLE: ONE voice across ALL tools and channels.                |
+-------------------------------------------------------------------------+
```

**Read top-down**: the objective (which funnel stage) picks the tools; the tools
carry creative; creative runs on media; media produces a measurable response. The
bridge: IMC is **API consistency across services** — every endpoint speaks the
same contract so the client experiences one coherent system, not a Frankenstein.

## The Promotion Mix

Five (now six, with digital) tools, each with different reach, cost, control, and
credibility.

```
+-----------------------------------------------------------------+
|                  THE PROMOTION MIX                              |
|                                                                 |
|  ADVERTISING       paid, non-personal, mass. High reach, low    |
|                    cost/contact, LOW credibility (it's paid).   |
|                                                                 |
|  SALES PROMOTION   short-term incentives (coupons, deals).      |
|                    Drives immediate action; can erode brand +   |
|                    train buyers to wait for deals.              |
|                                                                 |
|  PUBLIC RELATIONS  earned media, press, events. HIGH cred-      |
|                    ibility (not paid), LOW control.             |
|                                                                 |
|  PERSONAL SELLING  one-to-one, high-touch. Most persuasive +    |
|                    costly. Dominant in complex B2B.             |
|                                                                 |
|  DIRECT MARKETING  targeted, measurable, one-to-one at scale    |
|                    (email, etc.). Bridges to digital (08).      |
|                                                                 |
|  DIGITAL / SOCIAL  search, social, content, programmatic.       |
|                    Targeted + measurable. Detailed in 08.       |
+-----------------------------------------------------------------+
```

| Tool | Reach | Cost/contact | Control | Credibility | Best for |
|---|---|---|---|---|---|
| **Advertising** | High | Low | High | Low | Awareness, mass brand-building |
| **Sales promotion** | Med | Med | High | Low | Short-term action, trial |
| **PR** | Med-High | Low | Low | High | Credibility, launch buzz, crisis |
| **Personal selling** | Low | High | High | High | Complex/high-value B2B close |
| **Direct/digital** | Variable | Low-Med | High | Med | Targeted action, measurable |

### Push vs pull

```
  PUSH STRATEGY                      PULL STRATEGY
  -------------                      -------------
  Firm -> channel -> consumer        Firm -> consumer -> (asks) channel
  Promote TO the channel             Promote TO end-buyers; demand
  (trade deals, sales force)         pulls product through the channel
  Common: B2B, new products          Common: strong brands, advertising
```

Most programs blend push and pull. Personal selling and trade promotion are push
tools; advertising and consumer promotion are pull tools. The choice ties to your
channel strategy (`06`).

## Matching the Tool to the Funnel Stage

Different tools are efficient at different funnel stages. This is the core
allocation decision — and a frequent source of waste (using a brand-awareness tool
to try to close a deal, or vice versa).

```
+-----------------------------------------------------------------+
|  FUNNEL STAGE          MOST EFFICIENT TOOLS                     |
|  ------------          -------------------------------------    |
|  AWARENESS             advertising, PR, content, broad social   |
|     |                  (cheap reach, low credibility OK here)   |
|  CONSIDERATION         content, comparison, reviews, search     |
|     |                  (provide info, build judgments)          |
|  INTENT / EVALUATION   demos, trials, sales promotion, retarget |
|     |                  (reduce risk, prompt action)             |
|  PURCHASE              personal selling, direct, incentives     |
|     |                  (close; remove last friction)            |
|  LOYALTY / ADVOCACY    CRM, email, community, referral          |
|                        (retain, turn buyers into promoters)     |
+-----------------------------------------------------------------+
```

The **hierarchy-of-effects** model (cognitive -> affective -> behavioral: aware ->
know -> like -> prefer -> convinced -> buy) is the theory underneath: you move the
buyer one step at a time, and each tool is good at a different step. Spend matched
to stage is the efficient allocation; mismatched spend is the classic waste.

## Creative Strategy

Creative is *what you say* (the message) and *how you say it* (the execution).

```
+-----------------------------------------------------------------+
|                  CREATIVE = MESSAGE x EXECUTION                 |
|                                                                 |
|  MESSAGE (what)            EXECUTION (how)                      |
|  --------------            ---------------                      |
|  the value proposition     tone: emotional vs rational          |
|  the single key benefit    appeal: fear, humor, status, logic   |
|  the reason-to-believe     format: testimonial, demo, story     |
|  the call to action        the "big idea" / hook                |
|                                                                 |
|  RATIONAL appeals    -> high-involvement, info-seeking buyers   |
|  EMOTIONAL appeals   -> low-involvement, brand/feeling-driven   |
|                                                                 |
|  Discipline: ONE message per ad. Trying to say five things      |
|  says nothing. (Cognitive load, see behavioral-economics.)      |
+-----------------------------------------------------------------+
```

The **rational vs emotional** choice maps back to consumer behavior (`01`):
high-involvement buyers want information (rational, cognitive route);
low-involvement buyers respond to feeling (emotional, peripheral route). This is
the elaboration-likelihood model — central route (argument quality matters) vs
peripheral route (cues like attractiveness, music, celebrity matter). Match the
route to the buyer's involvement.

## Media Planning: The Quantitative Core

Media planning decides *where, how often, and when* to run, under a budget. This
is the most numeric part of promotion, with a precise vocabulary.

```
+-----------------------------------------------------------------+
|                  MEDIA MATH                                     |
|                                                                 |
|  REACH       % of target audience exposed AT LEAST ONCE in a    |
|              period. (Breadth.)                                 |
|                                                                 |
|  FREQUENCY   AVERAGE number of exposures per reached person.    |
|              (Depth.)                                           |
|                                                                 |
|  GRP         Gross Rating Points = REACH (%) x FREQUENCY        |
|              total exposure "weight" of a schedule.             |
|              e.g. reach 50% x avg freq 4 = 200 GRPs.            |
|                                                                 |
|  IMPRESSIONS total exposures = reach (people) x frequency.      |
|                                                                 |
|  CPM         Cost Per Mille = cost per 1,000 impressions.       |
|              = (cost / impressions) x 1000. The unit price.     |
|                                                                 |
|  EFFECTIVE   the minimum frequency (often ~3, the "rule of      |
|  FREQUENCY    three") below which the message doesn't register. |
+-----------------------------------------------------------------+
```

| Metric | Formula | Answers |
|---|---|---|
| **Reach** | unique people exposed / target | How many did I touch? |
| **Frequency** | total exposures / reached people | How often each? |
| **GRP** | reach % x frequency | Total schedule weight |
| **Impressions** | reach (people) x frequency | Total exposures |
| **CPM** | cost / impressions x 1000 | Price per 1,000 exposures |

### The reach vs frequency trade-off

A fixed budget forces a choice: touch *more* people *fewer* times (reach), or
*fewer* people *more* times (frequency). The math is a constraint:

```
  fixed GRPs (budget)  =  reach  x  frequency

  .-------------------.   .-------------------.
  | WIDE + SHALLOW    |   | NARROW + DEEP     |
  | high reach,       |   | low reach,        |
  | low frequency     |   | high frequency    |
  | (new product:     |   | (complex msg /    |
  |  build awareness) |   |  high-consider    |
  '-------------------'   |  purchase)        |
                          '-------------------'
```

Choosing the split is a **constrained-optimization** problem (maximize effective
exposure subject to a budget) — the same shape as capacity planning under a fixed
quota. The constraint: you cannot maximize both reach and frequency on a fixed
budget; pick the one your objective needs.

```
OLD WORLD                          MEDIA-PLANNING ANALOG
-----------------------------      -------------------------------------
QPS x duration = total requests    reach x frequency = total exposures
Cost per request / unit            CPM (cost per 1,000 impressions)
Coverage vs depth of testing       Reach vs frequency trade-off
Constrained optimization (quota)   Allocate GRPs under a fixed budget
```

## Sales Promotion: The Sharp Tool

Sales promotion (coupons, rebates, BOGO, limited-time deals) drives *immediate*
action but carries risks worth stating precisely.

| Benefit | Risk |
|---|---|
| Fast volume/trial spike | Pulls forward demand (borrows from the future) |
| Clears inventory | Trains buyers to *wait* for the next deal |
| Defends against rivals' promos | Erodes reference price -> hurts brand equity (`03`) |
| Measurable, attributable | Attracts deal-prone, low-loyalty switchers |

The deep risk is **reference-price erosion** (`behavioral-economics/02`): every
discount resets what buyers think the product "should" cost, lowering future WTP
and making the brand more elastic (`04`). Use promotion for genuine short-term
objectives (trial, launch, clearance), not as a standing crutch.

## Decision Cheat Sheet

| I want to... | Do this |
|---|---|
| Keep messaging coherent | Apply IMC — one voice across every tool and channel |
| Build broad awareness cheaply | Advertising, PR, content (high reach, low cost/contact) |
| Gain credibility at launch | PR / earned media (high credibility, low control) |
| Close complex B2B deals | Personal selling (costly but most persuasive) |
| Drive an immediate volume spike | Sales promotion — but watch reference-price erosion |
| Pick rational vs emotional creative | Match the buyer's involvement (high -> rational, low -> emotional) |
| Touch the most people (new product) | Maximize reach, accept lower frequency |
| Register a complex message | Maximize frequency to clear effective frequency (~3) |
| Compare media buys | Use CPM (cost per 1,000 impressions) |
| Allocate spend across the funnel | Match tool to stage; don't use awareness tools to close |

## Common Confusion Points

### "Reach and frequency are the same thing"

Reach is *how many distinct people* you touch; frequency is *how often each*. On a
fixed budget they trade off (their product is fixed GRPs). Confusing them produces
schedules that touch everyone once (no message registers) or a few people 50 times
(wasted, annoyed).

### "More frequency is always better"

There is a threshold (effective frequency, ~3) below which exposure is wasted, and
a ceiling above which you hit diminishing returns and wear-out (the ad annoys).
The goal is *enough* frequency on *enough* reach, not maximal frequency.

### "Sales promotion is free incremental volume"

Much of it is *pulled-forward* demand (you'd have sold it later) plus deal-seekers
who churn. Worse, repeated discounting erodes the reference price and raises
elasticity, weakening the brand. It's a sharp short-term tool, not a growth
engine.

### "Advertising is the whole of promotion"

Advertising is one of six tools. PR (credibility), personal selling (B2B close),
direct/digital (targeted action), and sales promotion (immediate volume) each do
jobs advertising does poorly. IMC is about *combining* them coherently.

### "CPM tells you which media is best"

CPM is a *cost-efficiency* metric (price per 1,000 exposures), not an
*effectiveness* one. A cheap CPM on the wrong audience, or with no attention, is
worse than a pricey CPM on the right one. Pair CPM with reach quality and measured
response (`09`).

### "IMC just means 'use many channels'"

IMC means *coordinating* channels so every message reinforces one positioning —
integration, not proliferation. Many channels saying inconsistent things is the
opposite of IMC; it's the Frankenstein the principle exists to prevent.
